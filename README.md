# Kris Bentley — Independent Consultancy Website

A complete eight-page static website ready for **free GitHub Pages hosting**.

## Publish (free)
1. Sign in to GitHub and create a **public** repository named `YOUR-USERNAME.github.io` (replace YOUR-USERNAME with your actual GitHub username).
2. Upload the contents of this folder (the `.html` files and `assets/` directory) to the repository root, then commit.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
4. Visit `https://YOUR-USERNAME.github.io/` after deployment completes.

Alternatively, a repository with any name can be published at `https://YOUR-USERNAME.github.io/REPOSITORY/` with the same Pages settings. All links here are relative.
